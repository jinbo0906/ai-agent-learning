## ⚠️ 实验路径修正（修正 A）

**问题**：强制默认基线需要 24GB 显存，与方案自述的小模型要求冲突，无卡者被硬卡死


**三条路径都必须满足的硬要求**：

- [ ] 有真实的前向、反向、参数更新（不接受伪代码，不接受只贴训练日志样例）
- [ ] 训练前后使用同一套评估，同时报告目标能力和能力保留集
- [ ] 记录：数据来源与过滤、学习率/batch/步数/随机种子、训练时长与显存、训练 loss、目标任务变化、保留集变化、至少一个失败或退化案例

### 路径 P1：有 >=24GB GPU（RTX 4090 / A100）

- 实验目录：`chapter7/continued-pretraining`
- 做法：沿用原路径（Mistral-7B + LoRA + 韩语续训 -> SFT），自带三阶段对比脚本和灾难性遗忘处理，最完整

### 路径 P2：有 8-16GB GPU 或云 Notebook（推荐大多数人）

- 实验目录：`chapter7/cot-distillation`
- 做法：换基座为 Qwen2.5-0.5B 或 1.5B 做 LoRA SFT，50-200 步。数据用 cot-distillation 生成并规则过滤。目标能力选一个可自动验证的窄任务（如固定格式工具调用生成），保留集用通用问答 20 题

### 路径 P3：完全无 GPU

- 实验目录：`chapter7/MiniMind-pretrain`
- 做法：训一个极小模型（几十 M 参数），CPU 可跑通完整预训练->SFT。任务效果差但参数更新真实，能亲眼看到 loss 下降与灾难性遗忘
- 💡 强烈建议改租按小时 GPU（约 2-4 元/小时，本实验 3 小时内完成，总成本 <15 元）走 P2
